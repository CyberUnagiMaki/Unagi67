# Unagi67 v0.5 — Custom presets / Свои пресеты

## English

- Create, rename and delete presets; choose a custom picture.
- 19 built-in presets named after their images; all can be deleted.
- Per-preset movement sensitivity and tapping rate, persistent selections and images.
- Settings survive app restarts and phone reboots.
- Configurable keyboard emergency STOP, default F8; middle-click STOP removed.
- Wi-Fi control + Bluetooth HID, without USB.

Install the APK over v0.4 to keep app data. Extract the Windows ZIP completely and keep `_internal` beside the EXE. Preserve `bridge_config.json` when updating the bridge.

This APK is debug-signed with the same certificate as the supplied v0.4 build. Tested on an Android emulator and Windows; physical-phone Bluetooth HID and in-game STOP still need device testing.

## Русский

- Создание, переименование и удаление пресетов, выбор своей картинки.
- 19 встроенных пресетов с названиями картинок; каждый можно удалить.
- Отдельные чувствительность и частота кликов для каждого пресета.
- Значения, выбор пресета и картинки сохраняются после перезапуска и перезагрузки.
- Настраиваемая клавиша STOP, по умолчанию F8; остановка средней кнопкой мыши убрана.
- Управление по Wi-Fi + Bluetooth HID, без USB.

Установи APK поверх v0.4 для сохранения данных. Распакуй Windows ZIP целиком и оставь `_internal` рядом с EXE. При обновлении моста сохрани `bridge_config.json`.

APK подписан debug-ключом, совпадающим с предоставленной v0.4. Проверено на Android-эмуляторе и Windows; Bluetooth HID на физическом телефоне и STOP в игре требуют проверки на устройстве.
