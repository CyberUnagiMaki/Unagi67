# Publish to GitHub / Публикация на GitHub

## Русский

1. Создай пустой репозиторий с названием `Unagi67` или своим названием.
2. Загрузи **содержимое** этой папки, сохранив `downloads/` и `screenshots/`. Не загружай внешний ZIP вместо содержимого: GitHub должен видеть `README.md` в корне.
3. README на английском откроется на главной странице; ссылка на русскую инструкцию уже добавлена. Ссылки на загрузки и картинки относительные и работают с любым именем репозитория.
4. При желании создай релиз с тегом `v0.5`, заголовком `Unagi67 v0.5 — Custom presets`, описанием из `RELEASE_NOTES.md` и приложи два файла из `downloads/`, а также `SHA256SUMS.txt`.

Краткое описание репозитория: `Android + Windows companion with Wi-Fi control, Bluetooth HID, custom presets and configurable emergency stop.`

В комплекте нет исходников приложения, ключей подписи и пользовательских настроек. Лицензия на исходники не добавлена: этот репозиторий распространяет готовые сборки. Комплект подготовлен локально; публикация в аккаунт GitHub не выполнялась.

## English

1. Create an empty repository named `Unagi67`, or use your preferred name.
2. Upload this folder's **contents**, keeping `downloads/` and `screenshots/`. Place `README.md` at the repository root rather than uploading the outer ZIP alone.
3. The English README links to Russian instructions. All download and screenshot links are relative and work with any repository name.
4. Optionally create release tag `v0.5`, title `Unagi67 v0.5 — Custom presets`, copy the release notes, and attach both files from `downloads/` plus `SHA256SUMS.txt`.

Application source, signing keys and user settings are excluded. No source-code license has been assigned. This is a local publication kit; nothing has been uploaded to GitHub.
