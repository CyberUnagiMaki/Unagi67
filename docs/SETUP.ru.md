# Установка и устранение проблем

[Главная](../README.ru.md) · [English](SETUP.en.md)

## Установка и подключение

1. Скачай APK и Windows ZIP с главной страницы. Установи APK на Android 9+ с поддержкой Bluetooth HID Device. Это debug-сборка. Для обновления существующей установки нужен тот же ключ подписи; перед возможным удалением сохрани значения пресетов.
2. Подключи устройства к одной доступной локальной сети. Телефон использует Wi-Fi, ПК может использовать Wi-Fi или Ethernet. Гостевая сеть и изоляция клиентов могут мешать подключению.
3. Открой Unagi и разреши Bluetooth. Разрешение уведомлений позволяет пользоваться управлением службы из уведомления. На экране показаны IPv4-адреса и код; выбери Wi-Fi-адрес, доступный с ПК.
4. Распакуй Windows-комплект полностью. Запусти `Unagi67_WiFi_Bridge.exe`, оставив папку `_internal` рядом.
5. Введи IP и код телефона, нажми **ПОДКЛЮЧИТЬ / WIFI**. Кабель, ADB и отладка по USB для работы не нужны.
6. Выполни Bluetooth-сопряжение через настройки, пока приложение открыто. Существующую рабочую пару можно сохранить. Регистрация HID, подключение и сопряжение — разные состояния: разрыв соединения сам по себе не требует удаления пары.
7. Нажми **ОТКАЛИБРОВАТЬ МЫШЬ**, затем ЛКМ физической мыши. Калибровка выбирает устройство Raw Input, которое будет управлять режимами.

## Управление

Нажатие на карточку переключает режим; на название — открывает настройки. Stroke управляет вертикальным движением, tapping — повторными кликами. После изменения значения сохрани пресет. Язык выбирается через шестерёнку.

**STOP** на телефоне или физическая средняя кнопка мыши выключает режимы. **DISCONNECT** останавливает службу Android, **START LINK** запускает её снова. После переподключения режимы остаются выключенными до ручного включения.

## Лупа

По умолчанию используется центр полных границ основного монитора, без вычитания панели задач и без объединения всех экранов. Для другого экрана нажми **ЦЕНТР ИГРОВОГО МОНИТОРА** и кликни в любом месте нужного монитора. Та же команда в настройках лупы на телефоне также сбрасывает ручные смещения X/Y.

При переходе на 0.4 старые смещения сбрасываются один раз. Последующие ручные смещения могут увести лупу от центра. Настраиваются кратность, размер и частота обновления; заданная частота — интервал планирования, а не гарантия фактического FPS.

Это центр монитора, а не маленького окна игры. Первую проверку удобнее проводить в безрамочном полноэкранном режиме. Поведение эксклюзивного fullscreen зависит от приложения.

## Работа после сворачивания

Соединением и вводом управляет foreground service. Сворачивание или закрытие Activity не должно останавливать её. Принудительная остановка Android завершает службу; ограничения батареи конкретной прошивки могут влиять на фон и выключенный экран. Проверка на физическом телефоне ещё требуется.

Если служба сама останавливается, проверь настройки фоновой работы/батареи для Unagi. При необходимости снова открой приложение и нажми **START LINK**. Приложение пытается восстановить соединение с последним успешно подключённым ПК, пока Bluetooth-пара сохранена.

## Возможные проблемы

| Симптом | Что проверить |
|---|---|
| Wi-Fi не подключается | Запущена ли служба, верны ли IP и код, одна ли сеть, нет ли изоляции клиентов |
| Неверный код | Вводи текущие шесть цифр со своего телефона, а не со скриншота |
| Wi-Fi подключён, действий нет | Bluetooth HID, калибровку физической мыши и включение режима |
| После обрыва режимы выключились | Это ожидаемо: включи их вручную после восстановления |
| Лупа не на том экране | Выбери игровой монитор и сбрось X/Y |
| Лупа не в центре окна игры | Она ориентируется на монитор, не на игровое окно |
| EXE не находит файлы | Распакуй весь комплект вместе с `_internal` |
| Android не даёт обновить приложение | Проверь ключ подписи; удаление может стереть пресеты |

Телефон слушает TCP-порт 5005. Программа не меняет правила брандмауэра. Протокол рассчитан на доверенную локальную сеть.
