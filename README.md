# Unagi67
A PC gaming input assistant designed to provide configurable shooting assistance.

Features
Vertical recoil compensation — automatically compensates for vertical mouse movement while firing. Compensation sensitivity can be adjusted.
Automatic Tap (Auto Tap) — automatically sends left mouse button clicks at a configurable rate while LMB is held down, allowing semi-automatic weapons to fire automatically.
Adjustable sensitivity — both modes can be individually configured to match a specific game, weapon, and playstyle.
Simple configuration — all major parameters can be adjusted directly through the application interface.

⚠️ Using input-assistance tools may violate the rules of some games and can result in restrictions or account bans. Use this project at your own risk.

Программа-ассистент для управления стрельбой в PC-играх.

Основные функции:

Компенсация вертикальной отдачи — автоматически корректирует вертикальное движение мыши во время стрельбы. Чувствительность компенсации можно настроить.
Автоматический тап (Auto Tap) — позволяет автоматически нажимать ЛКМ с заданной частотой при удержании кнопки мыши. Это позволяет использовать одиночное оружие в автоматическом режиме.
Настраиваемая чувствительность — параметры обоих режимов можно индивидуально настроить под конкретную игру, оружие и стиль управления.
Простая настройка — все основные параметры доступны непосредственно в интерфейсе приложения.

⚠️ Использование подобных инструментов может нарушать правила отдельных игр и приводить к ограничениям или блокировке аккаунта. Используйте проект на свой риск.
