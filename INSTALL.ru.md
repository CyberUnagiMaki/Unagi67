# UnagiSixSeven — Инструкция по установке и запуску


🇬🇧 [Read in English](INSTALL.md)

---

## Что у тебя есть

- **`UnagiSixSeven.apk`** — приложение для Android (устанавливаешь на телефон)
- **Папка с программой для ПК** — внутри `UnagiSixSeven_Bridge.exe`, `adb.exe` (и файлы рядом с ним), `pc_bridge_icon.ico`, `logo_small.png`

Устанавливать Python, Android Studio и что-либо ещё **не нужно** — всё необходимое уже в папке.

---

## Что понадобится

- Android-телефон с Bluetooth (Android 9 и новее)
- ПК на Windows с Bluetooth
- USB-кабель чтобы соединить их

---

## Шаг 1 — Установи приложение на телефон

1. Перекинь `UnagiSixSeven.apk` на телефон (по кабелю, через облако, мессенджер — как угодно).
2. Открой файл APK на телефоне чтобы установить.
3. Если появится предупреждение вроде *"Установка заблокирована"* или *"Неизвестные источники"* — нажми **Настройки** прямо в этом окне и разреши установку из этого источника, затем вернись назад и установи снова. Это предупреждение нормально — оно просто означает что приложение не из Google Play.

---

## Шаг 2 — Включи отладку по USB на телефоне

Это нужно чтобы программа на ПК могла общаться с телефоном по кабелю.

1. Открой **Настройки → О телефоне**.
2. Найди **Номер сборки** и тапни по нему **7 раз подряд**. Появится сообщение что режим разработчика включён.
3. Вернись в **Настройки**, открой **Для разработчиков** (появится новым пунктом в меню, обычно в разделе Система или в самом низу настроек).
4. Включи **Отладку по USB**.

---

## Шаг 3 — Подключи телефон и разреши соединение

1. Подключи телефон к ПК USB-кабелем.
2. На телефоне появится запрос: **"Разрешить отладку по USB?"** — нажми **Разрешить** (можно отметить "Всегда разрешать с этого компьютера" чтобы не видеть запрос каждый раз).

---

## Шаг 4 — Сопряги телефон как Bluetooth-мышь

Этот шаг нужно делать аккуратно, иначе Windows не создаст мышь правильно.

1. **Открой приложение UnagiSixSeven на телефоне и оставь его на экране** (не блокируй телефон и не переключайся на другое приложение). Это важно — телефон должен активно заявлять о себе как мышь.
2. Подожди примерно 10 секунд.
3. На ПК: открой **Параметры → Bluetooth и устройства → Добавить устройство**, найди телефон в списке и сопряги его.
4. После сопряжения проверь верх экрана приложения на телефоне — должно быть написано **"подключено: [имя телефона]"**. Если всё ещё написано "ждём подключения по Bluetooth" — что-то не зарегистрировалось, смотри решение проблем ниже.

**Каждый раз при новом запуске:** если приложение не показывает "подключено" в течение нескольких секунд после открытия — возможно придётся пересопрячь заново:
1. На ПК зайди в **Параметры → Bluetooth и устройства**, найди телефон в списке и **удали/забудь** его.
2. Открой приложение на телефоне (держи на переднем плане).
3. Сопряги заново из настроек Bluetooth ПК, как в шаге 3 выше.

Это известная особенность — Windows создаёт виртуальную мышь только когда видит что телефон заявляет себя мышью **именно в момент сопряжения**, поэтому иногда требуется пересопряжение если связь потерялась.

## Шаг 5 — Запусти программу на ПК

1. Открой полученную папку и дважды кликни на **`UnagiSixSeven_Bridge.exe`**.
   - Если Windows покажет предупреждение "Windows защитила ваш компьютер" (SmartScreen) — нажми **Подробнее → Всё равно запустить**. Это происходит потому что программа не имеет цифровой подписи, а не потому что она небезопасна.
2. Нажми **ПОДКЛЮЧИТЬ ПО USB**. Программа сама настроит USB-соединение с телефоном.
3. Нажми **ОТКАЛИБРОВАТЬ МЫШЬ**, затем один раз кликни **настоящей** левой кнопкой мыши. Это подсказывает программе за какой физической мышью следить.
4. Готово. Зажми настоящую левую кнопку мыши — в зависимости от того какой режим включён в приложении на телефоне, он будет либо плавно двигать курсор вниз (**Stroke**), либо кликать несколько раз (**Tapping**, только в полной версии).

**Клик колёсиком мыши = аварийный стоп.** Если что-то залипло — кликни колёсиком, состояние "зажато" мгновенно сбросится.

## Использование приложения

- **Две плитки на главном экране: Stroke и Tapping.** Тап в любом месте плитки — вкл/выкл этого режима. Тап именно по **названию** режима — открывает его настройки (скорость, пресеты).
- **Пресеты:** у каждого режима 11 именных пресетов, между которыми можно переключаться и которые можно настраивать.
- **Значок настроек (шестерёнка, верхний правый угол):** переключение языка приложения между английским и русским. У программы на ПК такая же опция в её собственной шапке.

## Решение проблем

| Проблема | Что делать |
|---|---|
| Приложение не устанавливается / "заблокировано Play Protect" | Разреши установку из этого источника в появившемся окне, или зайди в Настройки → Безопасность и разреши установку неизвестных приложений для того приложения которым открывал APK |
| ПК не видит телефон | Убедись что включена отладка по USB и ты нажал "Разрешить" на телефоне; попробуй другой USB-кабель — некоторые кабели только для зарядки, без передачи данных |
| Bluetooth сопрягается но приложение всё равно пишет "ждём подключения по Bluetooth" | Удали устройство из настроек Bluetooth Windows и сопряги заново с открытым приложением на переднем плане телефона |
| Калибровка не фиксирует клик мышью | Убедись что кликаешь настоящей мышью ПК, а не по экрану телефона, и что "ПОДКЛЮЧИТЬ ПО USB" прошло успешно |
| Windows SmartScreen блокирует exe | Нажми "Подробнее" → "Всё равно запустить" |
| Всё перестаёт реагировать через какое-то время | Кликни колёсиком мыши (аварийный стоп), затем попробуй снова |
